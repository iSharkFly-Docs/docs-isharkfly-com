# 看见颜料想起了自己学画的那几年

> 🔔 原文：https://www.isharkfly.com/t/topic/5275

就画画这件事来说，画来画去还是停留在素描的阶段。

虽然素描到最后画的还不错，但水彩和水粉这部分就实在是不咋地。

![IMG_3414|666x500](https://cdn.isharkfly.com/com-isharkfly-www/discourse-uploads/optimized/3X/7/9/79df551731c3757f4545ca407afe42dffecf982e_2_666x500.jpeg)

花不少钱，也不少时间，色彩就是一直无法精进，到最后也就不了了之的放弃。

不知道是不是正是这种选择，让现在的我做 UI 的就特别难看。

![IMG_3415|666x500](https://cdn.isharkfly.com/com-isharkfly-www/discourse-uploads/optimized/3X/e/5/e52684b99b27bc7e6d5269f77194b83c32d062a4_2_666x500.jpeg)

哪怕现在用 AI 的配色，都感觉比自己的眼光要好。

小时候花不少时间和精力的爱好，到最后都没有坚持下来。

当看的货架上的这些颜料，仿佛看到当年在货架前选择颜料时懵懂的童年。
