# 用 Mac 为国内小伙伴提供算力支持

> 🔔 原文：https://www.isharkfly.com/t/mac/9537

如果说是用树莓派是丐版配置，那么 Mac mini 就是妥妥的豪华版，是当前能够绕过 KYC 校验的不错选择。
